# VisualMadness

> Optimized and visual Fabric modpack with a pure vanilla feel.
> Оптимизированная и визуальная сборка на Fabric в чистом ванильном стиле.

---

## About / О проекте

**EN:** VisualMadness is a vanilla-focused modpack that makes the game look and feel like a cinematic trailer without breaking the original mechanics. We focus on two things: **maximum visual enhancement** and **excellent performance**.

**RU:** VisualMadness — это сборка, которая делает игру похожей на кинематографичный трейлер, не ломая оригинальную механику. Мы фокусируемся на двух вещах: **максимальное улучшение визуала** и **отличная производительность**.

---

## Features / Особенности

- **Optimized Performance / Оптимизация:** Built on top of Sodium, Lithium, Krypton, C2ME, and other top-tier performance mods to ensure stable FPS even on low-end PCs.
  *(Построена на базе Sodium, Lithium, Krypton, C2ME и других топовых модовx
  
- **Stunning Visuals / Потрясающий визуал:** Iris Shaders, 3D items, custom animations (Fresh Animations, Punchy), and atmospheric effects.
  *(Iris Shaders, 3D-предметы, кастомные анимации и атмосферные эффекты.)*

- **Ready-to-Play / Готово к игре:** Pre-configured settings and a custom FancyMenu interface.
  *(Готовые настройки и кастомное меню FancyMenu.)*

- **Pure Vanilla / Чистая ваниль:** No new dimensions, no new mobs, no new items. Just a better version of the game you love.
  *(Никаких новых измерений, мобов или предметов. Просто улучшенная версия любимой игры.)*

## Installation / Установка

**EN:**
1. Download the `.mrpack` file from the **Releases** section.
2. Open the Modrinth App or Prism Launcher.
3. Drag and drop the `.mrpack` file into the launcher.
4. Allocate 3-4 GB of RAM and launch the game.

**RU:**
1. Скачайте файл `.mrpack` в разделе **Releases** (Релизы).
2. Откройте лаунчер Modrinth App или Prism Launcher.
3. Перетащите файл `.mrpack` в окно лаунчера.
4. Выделите 3-4 ГБ ОЗУ и запустите игру.
